# 《推光》AI视频创作项目

目录核对日期：2026-10-19。目标：制作包含片尾在内的180秒纯AI工艺情境短片。本目录集中保存执行PDF、本轮生成的静态参考图、光线规范、资料来源与制作记录；静态资产交付不代表已经生成视频或完成成片验收。

## 当前执行资料

先阅读[资产与视觉提示词固定.pdf](01_制作文档/资产与视觉提示词固定.pdf)，锁定器物、纹样、人物、空间和光线；再阅读[分镜脚本.pdf](01_制作文档/分镜脚本.pdf)，按29个时间段逐镜制作。两份文件位于`01_制作文档/`，README采用它们当前的实际文件名，不以早期文件名代替。

[视觉资产目录](02_视觉资产/)集中存放本轮PNG参考图，已交付22张独立PNG（含1张双手身份母图）；具体文件、用途与尺寸见[资产清单与调用说明](01_制作文档/资产清单与调用说明.md)，可先看[资产总览](01_制作文档/资产总览.jpg)。这里的静态图用于固定视频生成时的形状、工序状态、手部和空间，不能直接当作已经验证成功的视频片段。

[光线规范](03_光线规范/L01_lighting.md)与[纯文本版本](03_光线规范/L01_lighting.txt)用于展开L01规则。具体镜头仍需结合对应工序状态图，不将所有参考图同时塞进一条提示词。

## 资料与记录

工艺资料为[平遥推光漆器技术规范](04_资料来源/平遥推光漆器技术规范_DB1407T008-2019.pdf)；赛事资料为[2026参赛指南](04_资料来源/2026参赛指南.pdf)和[评分标准及奖项设置](04_资料来源/2026评分标准及奖项设置.pdf)。资料各自只支持对应的工艺或赛事事实，不代表已经完成真实工坊访谈、实拍或专家审核。

[最终提示词集](05_制作记录/imagegen_最终提示词集.md)保存22张入选资产的实际提示词和输入参考，[图像生成记录](05_制作记录/imagegen_生成记录.jsonl)保留全部28次生成过程；候选与退回图集中在`05_制作记录/候选与退回/`，不要混入执行资产目录。[原文件迁移记录](05_制作记录/文件迁移记录_2026-10-19.json)保留归档时的路径与SHA256，[目录组织审计](05_制作记录/目录组织审计_2026-10-19.md)记录后续核对结果。

## 版本边界

`05_制作记录/历史稿/`中的早期合并PDF明确标注“勿作现行执行版”，保留追溯，不代替`01_制作文档/`的两份当前PDF。该目录另保留从旧输出位置复制的分镜快照；原处副本没有删除。

[PDF构建脚本](05_制作记录/脚本/build_production_pdfs.py)作为辅助制作记录保留，当前资产使用以现存执行PDF与资产清单为准。与本项目无关的CMC文件仍位于原`output/pdf/`，未作改动。

人物、器物和参考图属于创作设定，成片应继续明确其AIGC情境演绎性质，使用实际发生的生成、选择和修正记录说明人工贡献。

本轮图像使用内置imagegen生成；G01为白底布局参考，L01为文字规则。交付图片保留实际原始像素，不冒称视频成片分辨率。用户提供的规范截图副本保存在`04_资料来源/用户提供参考/`。
