# One More Pass｜《推光》AI视频创作项目 · v2

当前执行版为32镜、180秒，包含12秒片尾；三组前序工艺插叙合计40秒。主线是掌推、观察、选择继续、再次检查、最终停手。本目录保存脚本、静态资产与生成记录，视频和音频尚未生成。

先读[资产与视觉提示词固定.pdf](01_制作文档/资产与视觉提示词固定.pdf)，再按[分镜脚本.pdf](01_制作文档/分镜脚本.pdf)逐镜制作。两份原名PDF已更新，旧版保存在`05_制作记录/历史稿/叙事改版前_2026-10-19/`，旧版29镜不再执行。

原22图保留，本轮内置imagegen新增7图，合计29张独立PNG。可以先看[新增资产总览](01_制作文档/新增资产总览_v2.jpg)或[全部资产总览](01_制作文档/资产总览.jpg)，具体调用见[资产清单](01_制作文档/资产清单与调用说明.md)。L01为[文字光线规范](03_光线规范/L01_lighting.md)，不是第30张图片。

新增K01负责掌推接触，K02负责开场归置中断，K04与K03负责结尾同材质下的归置完成；R01/R02/R03负责三次固定构图检查。结尾不能用K02→K03连续生成，以免让光泽在放棉团时改变。棉团操作期间临放在工作垫固定留白区，结尾才放回小碟。

## 制作顺序

先依分镜中的样片方案试做30秒核心叙事，检查手部、反射与归置动作是否可读，再生成全片；样片在本次尚未制作。所有正式反射比较使用同样整洁的R系列，不能用P05C操作灰消失作为推光证明。

工艺依据见[地方技术规范](04_资料来源/平遥推光漆器技术规范_DB1407T008-2019.pdf)。赛事资料为[2026参赛指南](04_资料来源/2026参赛指南.pdf)及[评分标准](04_资料来源/2026评分标准及奖项设置.pdf)。道具、人物与窗影叙事属于AIGC情境演绎，不模拟真实传承人经历；实际模型、声音、素材使用及最终赛事标识仍按真实制作情况填写。
